# DistrictMender data

Generated by `scripts/build_dataset.py`. Do not commit large raw downloads (`data/states/*/raw/` is gitignored).

## Utah (FIPS 49)

Atomic unit is the **voting district (VTD)**. Census tracts sit between VTDs and counties.

| File | Purpose |
|------|---------|
| `manifest.json` | State metadata, total pop, ideal district pop, layer paths |
| `graph.json` | VTD adjacency graph + populations for solver |
| `vtds.geojson` | VTD polygons (atomic paint unit) |
| `tracts.geojson` | Tracts + `vtd_ids` / population for unit paint |
| `counties.geojson` | Counties + `vtd_ids` / population for unit paint |
| `vtd_pops.json` | Compact population array (`index = vtd id`) for the web UI |

Sources: Census TIGER2020PL VTDs / tracts / counties + PL 94-171 (SUMLEV 700).

## Rebuild

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python scripts/build_dataset.py
```
